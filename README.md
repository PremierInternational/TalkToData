TalkToData
--------------------------------------------------------------------
🛠️ Setup Instructions
Install Ollama
Download and install Ollama from the official website:
👉 https://ollama.com/download

---------------------------------------------------------------------
Place Ollama in the Project Folder
After downloading, copy the Ollama installer (or executable) into the same folder where setup.bat, app.py, and requirements.txt are located.

---------------------------------------------------------------------
Run the Setup File
Double-click the setup.bat file. 

This will:Install required Python packages using requirements.txt and Start the TalkToData application

---------------------------------------------------------------------
Open in Browser
Once started, the application will automatically open in your default browser.
